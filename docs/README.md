- [Portfolio y modelos](portfolio.md): proyectos, dashboards y modelos de contenido.
- [Gestión de contenido](gestion-de-contenido.md): uso de Django Admin y archivos multimedia.
- [Frontend](frontend.md): templates, estilos, JavaScript y recursos estáticos.
- [Seguridad](seguridad.md): configuración por entorno y archivos que no se versionan.
- [Desarrollo](desarrollo.md): instalación local, variables, tests, estáticos y producción.
- [Evolución](evolucion.md): cambios funcionales y técnicos observables en el repositorio.

Las especificaciones de funcionalidades permanecen en [../spec/](../spec/), siguiendo la estructura existente de constitution, features, planes y tareas.
