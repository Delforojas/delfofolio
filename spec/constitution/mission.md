# Misión del proyecto

## Qué construye el proyecto

El repositorio implementa una web personal / portfolio profesional desarrollada con Django. Su función principal es exponer información del autor en distintas secciones: portada, acerca de, tecnologías, portfolio, dashboards, datasets, formación, experiencia laboral y contacto.

La evidencia del código muestra que el contenido principal se gestiona desde Django Admin y se presenta mediante plantillas HTML con estilos estáticos.

## Para quién está pensado

Está pensado para una persona que quiere:

- mostrar su perfil profesional
- presentar visualmente las tecnologías y herramientas con las que trabaja
- presentar proyectos realizados
- presentar dashboards de Power BI
- publicar formación académica y cursos
- mostrar experiencia laboral
- compartir recursos o datasets
- publicar información de contacto profesional

## Objetivos observables

A partir del código actual, se pueden identificar estos objetivos:

- crear una presencia web personal con branding propio
- comunicar las capacidades técnicas mediante un catálogo visual organizado
- centralizar el contenido en modelos de Django
- permitir administración del contenido desde el panel de administración
- reutilizar un layout global para toda la web
- mostrar contenido multimedia como imágenes y certificados
- presentar proyectos y recursos con enlaces externos

## Principios del proyecto

Estos principios están respaldados por la estructura del repositorio:

1. Simplicidad de arquitectura: app por dominio y templates Django.
2. Contenido administrable: modelos con datos persistentes y panel admin.
3. Presentación visual estática: Bootstrap, jQuery y Font Awesome en assets de la app.
4. Enfoque monolítico: no se observa API REST ni frontend SPA en el código actual.
5. Mantener el contenido profesional en español, con nombres de campos y textos en español.

## Limitaciones detectadas

No puede afirmarse con certeza, a partir del repositorio, una misión comercial o de producto más amplia de la que se deduce de la estructura y el contenido visible. Tampoco se ha detectado documentación de objetivos de negocio más detallados fuera de la propia web personal.
