# Tareas para reproducir/verificar la feature Experiencia Laboral

1. Ejecutar migraciones.
2. Crear registros de `ExperienciaLaboral` desde Django Admin.
3. Completar cargo, empresa, fechas y descripción.
4. Iniciar el proyecto.
5. Visitar `/experiencialaboral/`.
6. Confirmar que la experiencia laboral aparece en la interfaz.

## Observación

No hay pruebas automatizadas ni datos semilla en el repositorio para esta feature.
