# Tareas para reproducir/verificar la feature Home

1. Activar el entorno virtual y instalar dependencias.
2. Ejecutar `python manage.py migrate`.
3. Arrancar el servidor con `python manage.py runserver`.
4. Abrir la ruta `/`.
5. Confirmar que la página muestra la portada con la presentación del autor.
6. Confirmar que el layout base y la navegación global están cargados.

## Observación

No hay pruebas automatizadas para esta feature en el repositorio actual.
