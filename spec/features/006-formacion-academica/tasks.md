# Tareas para reproducir/verificar la feature Formación Académica

1. Ejecutar migraciones.
2. Crear registros de `FormacionAcademica` desde el panel admin.
3. Completar institución, título, fechas y certificado opcional.
4. Arrancar el servidor.
5. Visitar `/experiencia/`.
6. Confirmar que la formación académica aparece ordenada según el modelo.

## Observación

No hay datos de ejemplo ni pruebas automatizadas en el repositorio actual para esta feature.
