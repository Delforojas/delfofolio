# Tareas para reproducir/verificar la feature Portfolio

1. Crear y aplicar migraciones.
2. Abrir Django Admin.
3. Crear uno o varios registros del modelo `Project`.
4. Asegurar que cada proyecto tenga una imagen y/o una URL opcional.
5. Iniciar el servidor con `python manage.py runserver`.
6. Visitar `/portfolio/`.
7. Confirmar que los proyectos se listan con sus datos.
8. Confirmar que se muestran enlaces y fechas cuando existen.

## Observación

No hay datos de ejemplo incluidos como fixtures ni pruebas automatizadas para esta feature.
