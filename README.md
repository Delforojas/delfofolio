# 📌 Proyecto Django – Aplicación Web

## 🧠 Descripción

Este proyecto consiste en una **aplicación web desarrollada con Django**, donde se han trabajado los conceptos fundamentales del framework para construir una estructura completa de backend.

El objetivo principal ha sido aprender a desarrollar aplicaciones web siguiendo una arquitectura organizada y escalable, integrando lógica de negocio, gestión de datos y presentación.

---

## ⚙️ Tecnologías utilizadas

- Python

- Django

- SQLite

- HTML / CSS / JavaScript

---

## 🏗️ Arquitectura

El proyecto sigue el patrón **MVT (Model–View–Template)** propio de Django:

- **Models** → definición y gestión de datos  

- **Views** → lógica de negocio  

- **Templates** → renderizado de la interfaz  

Además, el proyecto está estructurado en diferentes módulos (apps) para separar responsabilidades.

## 📌 Funcionalidades trabajadas

- Creación de proyectos y apps en Django

- Definición de modelos y base de datos

- Gestión de rutas y vistas

- Renderizado de templates dinámicos

- Integración frontend y backend

- Organización modular del código

---

## 🎯 Objetivo

- Comprender el funcionamiento de Django

- Aplicar arquitectura MVT

- Desarrollar aplicaciones web completas
