# Avisos del sprite local de iconos

`technology-icons.svg` agrupa símbolos locales para las secciones Tecnologías y Contacto. No se cargan iconos desde servicios externos durante el renderizado.

## Simple Icons

Fuente: https://github.com/simple-icons/simple-icons

Licencia: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/

Símbolos: Python, Django, JavaScript, TypeScript, PHP, Symfony, Angular, HTML5, CSS, Bootstrap, pandas, NumPy, Anaconda, scikit-learn, Git, GitHub, Docker, Postman, OpenCode, Model Context Protocol, Agent Skills, phpMyAdmin, PostgreSQL, MySQL, Instagram y Facebook.

Los SVG originales se adaptaron a elementos `symbol`; se retiraron títulos porque el nombre visible de cada tarjeta proporciona la etiqueta y el gráfico es decorativo. Cada símbolo usa su color de marca o una variante de marca con contraste suficiente sobre el fondo oscuro. El símbolo CSS se muestra con el texto visible CSS3.

## OpenAI

Fuente: https://openai.com/favicon.svg

Símbolo: OpenAI Blossom. El path oficial se adaptó a un elemento `symbol` local y usa `currentColor` para conservar contraste sobre el fondo oscuro.

## Devicon

Fuente: https://github.com/devicons/devicon

Licencia: MIT, https://github.com/devicons/devicon/blob/master/LICENSE

Copyright (c) 2015 konpa.

Símbolos: Matplotlib Plain y Visual Studio Code Plain.

Los SVG originales se adaptaron a elementos `symbol` y usan variantes de sus colores de marca legibles sobre el fondo oscuro.

## Microsoft Power BI Icons

Fuente: https://github.com/microsoft/PowerBI-Icons

Licencia de los iconos y contenido: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/

Autor: Microsoft y colaboradores del repositorio PowerBI-Icons.

Símbolos: SQL Query, Power BI, Power Query Colored y Function.

Los SVG originales se adaptaron a elementos `symbol` y se normalizaron identificadores internos. Power BI y Power Query mantienen sus colores originales. SQL usa el naranja de acento del portfolio y Function usa el amarillo de Power BI; Function se muestra con el texto visible DAX como alternativa semántica aprobada, ya que no existe un logo DAX específico en los catálogos revisados.

Las marcas y logotipos siguen perteneciendo a sus respectivos propietarios. Su inclusión identifica tecnologías y no implica patrocinio o afiliación.
